# पुल नहीं टिकते। · Probity AR

AR companion to a poster for **Vigilance Awareness Week 2026, IIM Mumbai** (theme: सत्यनिष्ठा से समृद्धि / Probity for Prosperity).

Scan the QR on the poster, then:
- **AR:** point your phone at the poster. Its layers lift into 3D, the headline breaks and falls with the bridge, and you tap to rebuild it.
- **3D:** the same scene without a camera, using tilt or drag.

Built with three.js and MindAR (image tracking). Static site, hosted on GitHub Pages.
